# 🧠 Smart To-Do App (Python CLI)

A simple yet powerful **offline to-do application** built using Python.  
This project helps manage daily tasks efficiently with priority sorting, search functionality, and persistent storage using files.

---

## 🚀 Features

- Add new tasks
- Assign priority (high / medium / low)
- Mark tasks as completed
- Search tasks easily
- Smart sorting by priority
- Persistent storage using `tasks.txt` (no data loss after closing app)
- Fully offline (no API or internet required)

---

## 🛠️ Tech Stack

- Python 3
- File Handling
- CLI (Command Line Interface)
- Data Structures (Lists & Dictionaries)
